# Lamlet logo

- [lamlet.svg](lamlet.svg): primary 1600×400 banner with `${λ} Lamlet` centered. The wordmark is muted
  gray (`#8A8A8A`) so the black `${λ}` expression stands out. The README shows it at full width.
- [lamlet-mark.svg](lamlet-mark.svg): square symbol for small placements.
- [lamlet.png](lamlet.png) (3200×800) and [lamlet-mark.png](lamlet-mark.png) (512×512): 2× raster copies
  of the SVGs, rendered with ImageMagick, for places that do not accept SVG.
- `-dark` variants of all four files ([lamlet-dark.svg](lamlet-dark.svg),
  [lamlet-mark-dark.svg](lamlet-mark-dark.svg), and their PNGs) invert the colors: white `${λ}`, `#757575`
  wordmark, `#1B1B1B` background.

The symbol is Lamlet's expression syntax around an upright lambda: `${λ}`. It is drawn in flat, heavy,
single-weight strokes with square ends. The `$` and braces have 45° chamfered outer corners; the λ is left
unchamfered. The symbol is black (`#000`); the background is light gray (`#E4E4E4`).

Both SVGs contain only vector paths, with accessible titles and no external images, fonts, scripts, or
stylesheets. Keep the viewBox proportions when resizing.

The symbol is original artwork. The wordmark uses DejaVu Sans Bold glyph outlines; the accompanying
[font license](DejaVu-LICENSE.txt) preserves its notices. The SVG is artwork, not a font distribution.
