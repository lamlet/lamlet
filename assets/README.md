# Lamlet logo

- [lamlet.svg](lamlet.svg): primary horizontal logo with an outlined wordmark.
- [lamlet-mark.svg](lamlet-mark.svg): square symbol for small placements.

The symbol places a lambda inside expression braces: `{λ}`. The palette uses ink `#263642` and terracotta
`#B85336`. Both SVGs have transparent backgrounds and contain only vector paths, with accessible titles and
no external images, fonts, scripts, or stylesheets. Keep the viewBox proportions when resizing.

The brace/lambda symbol is original artwork. The wordmark uses DejaVu Serif glyph outlines; the accompanying
[font license](DejaVu-LICENSE.txt) preserves its notices. The SVG is artwork, not a font distribution.
